1. 项目简介
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 
本项目是一套完整的皮肤病变 AI 分类与风险评估系统，可对皮肤镜图像
进行自动分析，输出三种类别的患病概率，并生成 Grad-CAM 热力图直观
展示模型关注的异常区域。
 
分类类别：
  ● 黑色素瘤（0_melanoma）       — 最高危皮肤癌
  ● 皮肤癌（1_other_cancer）     — 其他类型皮肤恶性肿瘤
  ● 非癌症/健康（2_other_conditions） — 良性或正常皮肤
 
核心技术：
  ● 模型架构 : ConvNeXt-Small（Meta AI，2022）
  ● 热力图   : Grad-CAM（梯度加权类激活映射）
  ● 损失函数 : HybridLoss（0.4×CrossEntropy + 0.6×FocalLoss）
  ● 权重策略 : EMA（指数移动平均）
  ● 混合精度 : AMP（自动混合精度，加速 GPU 训练）
  ● 前端框架 : Flask + 纯 HTML/CSS/JavaScript

      0_melanoma/       ← 放黑色素瘤训练图片（建议 ≥500 张）

  ● 训练集：验证集 = 8:2 或 7:3

  ● ISIC 2019/2020 数据集（皮肤镜图像）
  ● HAM10000 数据集

6. 训练模型（train.py）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 
【基础用法】
  python train.py
 
【训练流程说明】
 
  第 1 阶段（Phase 1，共 10 轮）：
    - ConvNeXt-S 骨干网络完全冻结
    - 只训练自定义分类头（Dropout → Linear → LayerNorm → GELU → Linear）
    - 学习率：5e-4，余弦退火衰减
    - 目的：快速适配新任务，防止预训练特征被破坏
 
  第 2 阶段（Phase 2，剩余轮次）：
    - 解冻全部网络，联合微调
    - 骨干学习率：2e-5（比分类头慢 10×）
    - 分类头学习率：2e-4
    - 目的：整体精细化调整
 
  ★ 前 5 轮还会进行 Warmup（线性学习率爬坡），防止初始震荡
 
【修改训练参数】
 
  打开 train.py，找到顶部的 CFG 字典，可修改以下参数：
 
  "batch_size"          : 32    → 显存不足时改为 16 或 8
  "num_epochs"          : 100   → 总训练轮数
  "early_stop_patience" : 15    → 连续多少轮无提升就停止训练
  "head_only_epochs"    : 10    → 第一阶段（冻结骨干）的轮数
  "data_dir"            : "./skin_cancer_data"  → 数据集路径
  "img_size"            : 224   → 输入图像尺寸（不建议改动）
 
【断点续训（自动）】
 
  训练中途关闭窗口后，再次运行 python train.py 会自动从断点恢复，
  无需任何额外操作。断点信息保存在 checkpoint_latest.pth 中。
 
【从头重新训练】
 
  Windows CMD 中运行：
  del checkpoint_latest.pth
  python train.py
 
【训练过程监控（TensorBoard）】
 
  另开一个 CMD 窗口，运行：
  tensorboard --logdir ./runs/skin_cancer_v2
  然后浏览器打开：http://localhost:6006
 
  可查看：Loss / Accuracy / MacroF1 / Per-class F1 / 学习率 / AUC 曲线
 
【训练结束后生成的文件】
 
  best_model.pth              ← 最优模型权重（验证集 MacroF1 最高）
  best_model.onnx             ← ONNX 部署格式（可用于生产环境）
  best_model_scripted.pt      ← TorchScript 格式（C++ 可直接加载）
  checkpoint_latest.pth       ← 断点续训文件
  training_log.csv            ← 每轮训练指标（可用 Excel 打开）
  reports/
    confusion_matrix_best.png       ← 混淆矩阵图
    roc_curves_best.png             ← ROC 曲线图（含 AUC）
    classification_report_best.txt  ← 详细分类报告
 
【如何判断训练是否良好】
 
  良好信号（✅）：
  - Val MacroF1 稳定上升，15 轮内持续刷新最高值
  - Train Loss 和 Val Loss 同步下降，差距不超过 0.2
  - AUC > 0.80（Phase 2 后期）
 
  需要注意（⚠️）：
  - Val Loss 上升但 Train Loss 继续下降 → 过拟合，可减少 num_epochs
  - 所有类别 F1 都很低（< 0.3）且不上升 → 检查数据集是否正确
  - 黑色素瘤 F1 长期 < 0.4 → 数据严重不平衡，可增加该类图片数量

7. 单独推理（infer.py）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 
infer.py 是纯命令行推理脚本，适合脚本自动化调用。
如果只需要可视化界面，直接使用 app.py 即可，不必用此文件。
 
【单张图片推理（默认开启 TTA）】
  python infer.py --image 图片路径.jpg
 
【文件夹批量推理】
  python infer.py --folder ./test_images
 
【保存结果为 JSON 文件】
  python infer.py --folder ./test_images --output results.json
 
【关闭 TTA（速度提升约 8 倍，精度略低）】
  python infer.py --image 图片.jpg --no-tta
 
【加载 TorchScript 格式模型】
  python infer.py --image 图片.jpg --model best_model_scripted.pt --torchscript
 
【TTA 说明（测试时数据增强）】
  TTA（Test-Time Augmentation）会对每张图片生成 8 种不同变换：
    1. 原图
    2. 水平翻转
    3. 垂直翻转
    4. 水平+垂直翻转
    5. 旋转 90°
    6. 旋转 180°
    7. 旋转 270°
    8. 放大 1.15× 后中心裁剪
  将 8 次推理的概率取平均值，通常可提升 0.5%~2% 准确率。
  推理结果还会附带「不确定性估计」（±标准差），值越小表示模型越稳定。

【启动步骤】
 
  Step 1：将待检测的皮肤图片复制到项目文件夹中的 orgimg/ 子文件夹
          （首次运行会自动创建该文件夹）
 
  Step 2：运行以下命令启动服务器：
          python app.py
 
  Step 3：打开浏览器（推荐 Chrome / Edge），访问：
          http://localhost:5000
 
  Step 4：点击「⚡ 开始批量分析」，等待处理完成
 
  Step 5：处理完成后，结果会实时显示在页面右侧
 
【界面说明】
 
  左侧面板：
    - 显示 orgimg/ 中所有待处理图片列表
    - ✅ 绿色 = 已处理完成
    - ⚙️ 蓝色闪烁 = 正在处理
    - 进度条显示整体完成进度
 
  右侧结果区（每张图片一张卡片）：
    - 左列：原始图像
    - 中列：Grad-CAM 热力图
        🔴 红色区域 = 黑色素瘤相关异常激活
        🔵 蓝色区域 = 皮肤癌相关异常激活
        🟢 绿色区域 = 非癌症/健康相关特征
        颜色越深 = 该区域对对应类别的影响越大
    - 右列：三类概率条形图 + 风险等级 + 查看报告链接
 
  顶部状态栏：
    - 显示当前使用的 GPU 型号（或 CPU）
    - 显示模型是否成功加载
 
【风险等级定义】
  高风险（红色）：置信度 ≥ 65%  → 强烈建议立即就医
  中风险（黄色）：置信度 ≥ 35%  → 建议近期随访复查
  低风险（绿色）：置信度 < 35%  → 暂时风险较低，保持观察
 
【停止服务器】
  在运行 python app.py 的 CMD 窗口中按 Ctrl+C

10. 常见问题排查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 
【问题】CUDA out of memory（显存不足）
  解决：打开 train.py，将 CFG 中的 batch_size 从 32 改为 16 或 8
 
【问题】ModuleNotFoundError: No module named 'xxx'
  解决：按照第 4 节重新安装对应依赖
  pip install xxx
 
【问题】app.py 启动后浏览器显示"无法访问此网站"
  解决：确认 CMD 窗口中没有报错，端口 5000 未被占用
  换用其他端口：修改 app.py 最后一行
  app.run(host="0.0.0.0", port=5001, ...)
  然后访问 http://localhost:5001
 
【问题】前端显示"模型未加载"（顶部黄色警告）
  解决：确认 best_model.pth 与 app.py 在同一文件夹
  如果还没训练过，先运行 python train.py
 
【问题】训练时 AUC 一直显示 0.5000
  解决：此 bug 已在新版 train.py 中修复。
  如果仍出现，检查是否使用了最新版本的 train.py
 
【问题】处理图片时 app.py 报错 "cv2 not found"
  解决：重新安装兼容版本 OpenCV
  pip install "numpy==1.26.4"
  pip install "opencv-python-headless==4.9.0.80"
 
【问题】命令行中 rm 命令无法使用（Windows）
  解决：Windows 使用 del 代替 rm，使用 rmdir 代替 rm -rf
  del checkpoint_latest.pth
  rmdir /s /q reports runs
 
【问题】训练好几轮但 Macro F1 没有提升
  可能原因及解决：
  a. 数据集太小       → 增加每类图片数量至 500 张以上
  b. 学习率过高       → 将 head_lr 从 5e-4 改为 1e-4
  c. 类别严重不平衡   → 补充少数类（黑色素瘤）的图片
 
【问题】热力图全黑或几乎看不到颜色
  可能原因：Grad-CAM 对该类别的激活很弱
  这通常意味着模型对这张图片很有把握（概率接近 100%），
  梯度接近 0，导致热力图不明显。这是正常现象。
